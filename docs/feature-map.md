## 模块详情

### 🏠 首页仪表盘
- 今日待办任务数量
- 今日习惯打卡状态
- 近期提醒汇总（冰箱临期、账单到期、宠物提醒）
- 冰箱临期食材数量
- 本月支出总额
- 旅行倒计时
- AI 生活建议
- 快捷入口（10个模块快速跳转）

### 🧹 家务分工
- 家务任务 CRUD
- 成员分配
- 优先级/截止日期
- 完成状态追踪
- 积分排行

### ✅ 习惯打卡
- 习惯 CRUD（名称、分类、图标）
- 每日打卡
- 连续天数 / 最佳连续天数
- 分类筛选（健康、学习、工作、生活、宠物）
- 本周统计

### 📋 生活清单
- 30+ 场景模板
- 自定义清单项
- 勾选完成
- 进度追踪

### 🛒 购物清单
- 商品 CRUD（名称、分类、价格、数量）
- 分类筛选
- 已购/待购切换
- 预算统计
- 冰箱联动补货

### 💰 生活账本
- 收支记录 CRUD
- 分类统计
- 预算管理
- 图表展示

### 💳 账单管理
- 账单 CRUD（名称、金额、到期日、分类）
- 付款标记
- 逾期高亮
- 即将到期提醒（7天内）
- 月度统计（总额/已付/未付）
- 频率管理（一次性/每月/每季/每年）

### 🧊 冰箱食材
- 食材 CRUD（名称、数量、分类、过期日期）
- 9大分类（蔬菜、水果、肉类、海鲜、乳制品、调味品、饮料、冷冻、零食）
- 临期提醒（3天内）
- 已过期标记
- 一键加入购物清单
- 菜谱推荐
- 一周菜单

### 🍳 菜谱速查
- 20道菜谱
- 分类筛选（早餐、正餐、甜品、咖啡、饮品）
- 搜索功能
- 收藏功能
- 快速/详细模式切换
- 食材列表 + 步骤 + 小贴士

### 🐕 宠物生活
- 宠物档案（名字、品种、生日、体重）
- 10条提醒（喂食、饮水、清洁、遛宠、疫苗、体检）
- 提醒开关
- 完成标记
- 宠物日记（内容 + 心情）
- 今日任务统计

### ✈️ 旅行计划
- 计划 CRUD（标题、目的地、日期、预算）
- 出发倒计时
- 待办清单（勾选完成）
- 行李清单（勾选完成）
- 每日行程卡片
- 3条示例计划（日本行、露营、国庆回家）

### 🤖 AI 助手
- 关键词匹配建议引擎
- 8条规则（时间管理、菜谱推荐、旅行打包、宠物照顾、理财建议、习惯养成、家务建议、购物建议）
- 快捷问题入口
- 对话历史
- 建议按钮跳转
- 预留真实 AI API 接口

### 🔍 全局搜索
- 跨模块搜索（任务、习惯、食材、菜谱、旅行、宠物、账单、购物）
- 实时搜索（防抖）
- 结果分组展示
- 搜索历史
- 热门搜索
- 无结果状态

### 👔 衣橱洗衣
- 衣物 CRUD
- 脏衣篮管理
- 季节分类
- 穿搭建议

### 🏠 房间整理
- 区域管理
- 整理任务
- 每周挑战
- 进度追踪

### 👤 个人中心
- 用户信息
- 生活积分系统
- 数据概览统计
- 菜单导航（15+ 功能入口）
- 深色模式切换
- 提醒通知查看
- 数据导出
- 缓存管理

## 模块间联动

| 源模块 | 目标模块 | 联动方式 |
|--------|----------|----------|
| 冰箱食材 | 购物清单 | 一键加入购物清单 |
| 冰箱食材 | 菜谱速查 | 根据库存推荐菜谱 |
| 冰箱食材 | 首页仪表盘 | 临期食材提醒 |
| 账单管理 | 首页仪表盘 | 未付账单/逾期提醒 |
| 宠物生活 | 首页仪表盘 | 今日宠物任务 |
| 旅行计划 | 首页仪表盘 | 出发倒计时 |
| 习惯打卡 | 首页仪表盘 | 今日已打卡状态 |
| 所有模块 | 全局搜索 | 跨模块搜索 |
| 所有模块 | AI 助手 | 关键词匹配建议 |
| 所有模块 | 通知服务 | 聚合提醒 |
