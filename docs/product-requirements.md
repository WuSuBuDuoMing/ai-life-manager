# 产品需求文档（PRD）

> AI 生活管家 - 微信小程序
> 版本：v1.0
> 更新日期：2026-06-09

---

## 一、产品概述

### 1.1 产品定位

AI 生活管家是一款面向年轻人群的一站式生活管理微信小程序。它将日常生活中高频出现的家务分工、购物、记账、食材管理、衣物管理等场景整合到一个应用中，通过清爽的卡片式界面和智能提醒，帮助用户建立有序、高效的生活习惯。

**核心价值主张**：用一个小程序解决年轻人 80% 的日常管理需求，不再需要在多个 App 之间来回切换。

### 1.2 目标用户

| 用户群体 | 典型场景 | 核心需求 |
|---------|---------|---------|
| **大学生** | 宿舍生活、小组作业、日常消费 | 清单管理、简单记账、日程规划 |
| **留学生** | 独立生活、做饭买菜、订阅管理 | 冰箱管理、购物清单、账本、订阅追踪 |
| **情侣/同居伴侣** | 分担家务、共同消费、共享空间 | 家务分工、共享账本、购物清单 |
| **合租室友** | 公共区域清洁、费用分摊、物品管理 | 家务轮值、费用分摊、房间整理 |
| **年轻家庭** | 育儿家务、家庭开支、食材采购 | 家务计划、预算管理、冰箱管理 |

### 1.3 产品目标

- **短期目标（MVP v1.0）**：完成9大核心模块的基础功能上线，用户可通过微信小程序体验完整的生活管理流程
- **中期目标（v1.1-v1.2）**：接入真实后端，实现数据云同步，增强AI智能建议能力
- **长期目标（v2.0+）**：引入社交功能，支持家庭/室友多人协作，构建生活管理社区

## 三、非功能需求

### 3.1 性能要求

| 指标 | 要求 |
|------|------|
| 首页加载时间 | 首次加载 <= 2秒，后续页面 <= 1秒 |
| 操作响应时间 | 按钮点击到反馈 <= 300ms |
| 动画帧率 | 过渡动画 >= 60fps |
| 内存占用 | 运行时内存 <= 50MB |
| 包体积 | 主包 <= 2MB，总包 <= 8MB |
| Storage容量 | 单条记录 <= 200KB，总占用 <= 10MB |

### 3.2 兼容性要求

| 维度 | 要求 |
|------|------|
| 微信版本 | 基础库 2.25.0 及以上 |
| iOS | iOS 12.0 及以上 |
| Android | Android 7.0 及以上 |
| 屏幕尺寸 | 适配 320px ~ 428px 宽度 |
| 横竖屏 | 仅支持竖屏模式 |

### 3.3 安全要求

| 维度 | 要求 |
|------|------|
| 数据存储 | 敏感数据（如密码）不得明文存储 |
| 输入校验 | 所有用户输入必须进行长度和格式校验 |
| XSS防护 | WXML模板自动转义，不使用rich-text渲染用户输入 |
| 权限最小化 | 仅申请必要的小程序权限 |
| 数据隔离 | 不同用户数据严格隔离 |

## 五、MVP 范围定义

### 5.1 MVP 包含内容

MVP（最小可行产品）聚焦于4个P0模块的基础功能，确保用户可以完成核心生活管理流程：

1. **首页仪表盘**：今日任务概览、快捷入口、基础统计
2. **家务分工**：创建任务、分配成员、标记完成、积分排行
3. **生活清单**：创建清单（含模板）、添加清单项、勾选完成、进度展示
4. **购物清单**：添加商品、分类管理、标记已购买、预算统计
5. **生活账本**：快速记账、分类统计、月度汇总
6. **设置页面**：暗黑模式切换、关于我们

### 5.2 MVP 不包含内容

- 用户登录注册（使用本地数据）
- 数据云同步
- AI智能建议
- 推送通知
- 社交分享功能
- 多语言支持

### 5.3 MVP 验收标准

- 用户可以在30秒内完成一笔记账操作
- 用户可以使用模板在10秒内创建一个清单
- 用户可以查看本周家务分配情况
- 所有数据在关闭小程序后不丢失
- 暗黑模式下所有页面可正常阅读和操作
