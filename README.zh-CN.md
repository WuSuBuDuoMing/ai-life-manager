# 🏠 AI 生活管家 - 微信小程序

> **本地优先的一站式生活管理系统**

一款面向年轻人的微信小程序，整合任务管理、习惯打卡、饮食菜谱、冰箱库存、宠物照顾、旅行计划、账单提醒、AI 生活助手等 15+ 功能模块。用清爽的卡片式界面和智能提醒，帮助你把日常生活变得更有秩序。

## 🎯 核心功能

### 1. 🧹 家务分工模块
- **智能计划生成**：根据家庭成员数量和房间类型，自动生成家务计划，支持按周/月轮值
- **积分排行系统**：完成家务获得积分，实时排行榜激励家庭成员积极参与
- **轮值表管理**：自定义轮值周期，自动轮换分工，公平合理不扯皮

### 2. ✅ 生活清单模块
- **模板快速创建**：内置搬家清单、出差清单、旅行清单等常用模板，一键生成
- **分类管理**：支持自定义分类，按优先级排序，重要事项不遗漏
- **进度可视化**：实时显示完成进度百分比，清单完成有成就感

### 3. 🛒 购物清单模块
- **智能分类**：商品自动按食品、日用品、生鲜等分类，购物更有条理
- **预算管理**：设置预计花费，实时统计已购金额，超支预警提醒
- **冰箱联动**：冰箱食材快过期时，一键添加到购物清单，不浪费不遗忘

### 4. 📡 订阅管理模块
- **全量订阅追踪**：记录所有订阅服务（视频、音乐、云存储等），一目了然
- **续费智能提醒**：到期前3天/7天自动提醒，避免意外扣费
- **费用月度统计**：汇总每月订阅支出，帮你审视哪些订阅值得续费

### 5. 💰 生活账本模块
- **快速记账**：3秒完成一笔收支记录，支持自定义分类和备注
- **多维统计**：按周/月查看收支趋势，分类饼图直观展示消费结构
- **预算管理**：设置月度预算，实时追踪消费进度，超支时及时提醒
- **异常检测**：自动识别异常大额支出和重复扣款，账目清晰无遗漏

### 6. 🥦 冰箱食材模块
- **库存管理**：记录冰箱中每种食材的数量、保质期和存放位置
- **过期提醒**：临期食材提前3天预警，减少食物浪费
- **智能菜谱**：根据冰箱现有食材推荐菜谱，今天吃什么不再纠结
- **一周菜单**：AI 根据库存自动生成一周菜单计划，营养均衡不重样

### 7. 👔 衣橱洗衣模块
- **衣物档案**：为每件衣物建立档案，记录颜色、季节、场合等属性
- **脏衣篮管理**：智能提醒哪些衣物该洗了，洗衣不再遗漏
- **季节收纳**：换季时一键标记收纳衣物，找衣服不用翻箱倒柜
- **穿搭建议**：根据天气和场合推荐穿搭方案，出门不纠结

### 8. 🏠 房间整理模块
- **区域管理**：将房间划分为多个区域（书桌、衣柜、床底等），逐个击破
- **整理挑战**：设定整理目标和截止日期，游戏化完成整理任务
- **物品定位**：记录重要物品的存放位置，再也不用到处找东西

### 9. 🤖 AI 智能建议
- **生活洞察**：基于你的使用数据，提供个性化的生活改善建议
- **趋势预测**：分析消费趋势、食材消耗规律，帮你提前规划
- **跨模块联动**：冰箱食材快过期时建议菜谱，账本超支时建议节省方案

## 🚀 快速开始

### 第一步：克隆项目

```bash
git clone https://github.com/your-username/AI-life-manager-miniapp.git
```

### 第二步：导入微信开发者工具

1. 打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」
3. 项目目录选择克隆下来的文件夹
4. AppID 可先使用测试号或填入你自己的 AppID

### 第三步：替换 AppID

打开 `project.config.json`，将 `appid` 字段替换为你自己的小程序 AppID：

```json
{
  "appid": "your-app-id-here",
  "projectname": "AI-life-manager",
  ...
}
```

完成以上三步后，即可在模拟器中预览和调试小程序。

## 🎨 设计风格

### 设计理念

- **清爽**：大量留白，信息密度适中，视觉不疲劳
- **生活感**：温暖的色调搭配 emoji 图标，贴近日常生活场景
- **卡片式**：所有内容以卡片为单位承载，信息边界清晰
- **一致性**：统一的圆角、阴影、间距规范，贯穿所有页面

### 配色方案

| 用途 | 亮色模式 | 暗黑模式 |
|------|---------|---------|
| 主背景 | `#F5F5F5` | `#1A1A2E` |
| 卡片背景 | `#FFFFFF` | `#16213E` |
| 主色调 | `#4CAF50` | `#66BB6A` |
| 主文字 | `#333333` | `#E0E0E0` |
| 副文字 | `#999999` | `#888888` |
| 强调色 | `#FF9800` | `#FFA726` |
| 警告色 | `#F44336` | `#EF5350` |

### 暗黑模式

通过 CSS Variables 实现一键切换暗黑模式：

```css
/* 亮色主题 */
page {
  --bg-primary: #F5F5F5;
  --bg-card: #FFFFFF;
  --text-primary: #333333;
  --color-accent: #4CAF50;
}

/* 暗黑主题 */
page.dark {
  --bg-primary: #1A1A2E;
  --bg-card: #16213E;
  --text-primary: #E0E0E0;
  --color-accent: #66BB6A;
}
```
